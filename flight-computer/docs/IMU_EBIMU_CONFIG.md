# EBIMU-9DOFV6 설정

현재 M7 펌웨어는 230400 baud에서 다음 12필드 ASCII 출력을 받는다.

```text
*roll,pitch,yaw,gx,gy,gz,ax,ay,az,dx,dy,dz
```

출력 설정은 IMU에 저장한다. 비행 펌웨어는 부팅 때 이 형식을 다시 설정하지
않으므로 센서를 교체하거나 초기화한 뒤에는 설정을 확인해야 한다.

## 출력과 측정 범위

| 명령 | 설정 |
|---|---|
| `<sof1>` | Euler 자세각, deg |
| `<sog1>` | 각속도 출력, dps |
| `<soa3>` | 중력을 제거한 전역 좌표계 가속도, g |
| `<som0>` | 지자기 출력 끄기 |
| `<sod2>` | 전역 좌표계 적분 위치 출력, m |
| `<sor10>` | 출력 주기 10ms, 100Hz |
| `<sb6>` | UART 230400 baud |
| `<ssa4>` | 가속도 측정 범위 ±16g |
| `<ssg5>` | 각속도 측정 범위 ±2000dps |

설정 후 한 줄에 숫자 12개가 들어오는지 확인한다. 온도 등 다른 필드를
추가하면 현재 파서가 해당 줄을 거부한다.

`soa3`에서는 정지했을 때 가속도 세 축이 모두 0에 가까워야 한다.
발사 판단에 쓰는 Z축 가속도는 중력이 제거된 전역 수직 가속도다.
`sod2`의 적분 위치는 시간이 지나면 오차가 누적되며, 비행 판단에는 쓰지 않는다.

## 설정 명령 보내기

아래 스케치를 M7에 임시로 업로드하면 USB 시리얼 터미널에서 IMU와 직접
통신할 수 있다. 터미널은 115200 baud로 연다. `IMU.begin()`의 속도는
센서에 현재 저장된 속도와 맞아야 한다. IMU 속도를 바꾼 뒤에는 이 값도
바꾸어 다시 업로드한다.

```cpp
#include <Arduino.h>

UART IMU(PJ_8, PJ_9, NC, NC);

void setup() {
    Serial.begin(115200);
    IMU.begin(230400);
}

void loop() {
    while (Serial.available()) IMU.write((uint8_t)Serial.read());
    while (IMU.available()) Serial.write((uint8_t)IMU.read());
}
```

작업이 끝나면 [비행 펌웨어](../README.md#2-업로드)를 다시 업로드한다.

## 확인과 보정

| 명령 | 용도 |
|---|---|
| `<cfg>` | 저장 설정 확인. 확인 후 `>`를 보내 스트림 재개 |
| `<ver>` | 센서 펌웨어 버전 확인 |
| `<posz>` | 누적 속도·거리 초기화 |
| `<cg>` | 정지 상태에서 자이로 보정 |
| `<cmf>` | 센서를 회전하며 자기계 보정, `>`로 종료 |
| `<caf>` | 가속도 정밀 보정 |
| `<lf>` | 공장 초기화. 이후 출력 형식과 통신 속도를 다시 설정해야 함 |

비행 펌웨어의 부팅 절차에도 자이로 보정, 위치 초기화와 자기계 보정이
포함되어 있다. 부팅 로그에 맞춰 정지와 회전 구간을 구분한다.

과거 로그를 해석할 때는 당시 출력 설정도 확인한다. 이전 `som1` 설정의
로그에서는 `pos` 열에 지자기 값(µT)이 저장되었고, 현재 `sod2` 설정에서는
적분 위치(m)가 저장된다.
