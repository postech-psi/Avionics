# EBIMU-9DOFV6 확정 설정 (2026-07-25, 데이터시트 rev1.0 기준 검증)

비행 펌웨어(단일코어 main.cpp / 듀얼코어 main_m7.cpp)의 IMU 파서는
**12필드 ASCII 라인** `*R,P,Y,gx,gy,gz,ax,ay,az,dx,dy,dz`만 파싱한다.
이 포맷을 만드는 IMU 설정은 아래와 같고, **모든 설정은 IMU 내부 비휘발성 메모리에
저장**되므로 한 번 설정하면 전원을 꺼도 유지된다.

## 확정 출력 설정 (하드웨어 적용·검증 완료)

| 명령 | 값 | 의미 |
|---|---|---|
| `<sof1>` | Euler | Roll/Pitch/Yaw (deg, 소수 2자리) |
| `<sog1>` | ON | 자이로 (dps) |
| `<soa3>` | ON | 가속도 — **중력보정, Global 좌표계**, g 단위 (정지 시 3축 모두 ≈ 0) — 2026-07-25 soa1에서 변경 |
| `<som0>` | OFF | 지자기 출력 안 함 (내부 자세연산에는 sem2로 계속 사용됨) |
| `<sod2>` | ON | 거리(위치) — **Global 축**(동서남북/상하), m 단위 → 펌웨어 `pos[3]` |
| `<sor10>` | 100Hz | 출력 주기 10ms |
| `<sb6>` | 230400 | UART 속도 — 2026-07-26 sb5(115200)에서 상향(100Hz 스트림이 115200의 87%를 점유했었음) |

출력 순서는 고정: `sof → sog → soa → som → sod → sot → sots` (매뉴얼 p.12).

센서 감도(확인됨, 로켓에 적정): `ssa4`(±16g), `ssg5`(±2000dps).

## 유용한 명령

- `<cfg>` … `>` : 전체 설정 덤프 (출력 후 `>` 입력해야 스트림 재개)
- `<posz>` : 누적 속도/거리 0으로 리셋 (발사 직전 권장 — 기존 캘리 코드가 이미 호출함)
- `<cg>` : 자이로 캘리 (정지 상태, ~2s)
- `<cmf>` … 회전 … `>` : 지자기 캘리 (환경 바뀌면 재실행, 후에 `<reset>` 권장)
- `<caf>` … 회전 … `>` : 가속도 정밀 캘리
- `<lf>` : 공장초기화 (⚠️ 위 출력 설정 전부 소실 — 실행 시 이 문서대로 재설정)
- `<ver>` : 펌웨어 버전

설정 명령을 보내려면 아래 USB↔IMU 패스스루 스케치를 M7에 임시로 플래시한 뒤
시리얼 터미널(115200)에서 입력한다 (작업 후 production 펌웨어 재업로드):

```cpp
#include <Arduino.h>
UART IMU(PJ_8, PJ_9, NC, NC);   // main_m7.cpp와 동일 핀
void setup() { Serial.begin(115200); IMU.begin(230400); }  // IMU=sb6. 공장초기화 직후라면 115200
void loop() {
    while (Serial.available()) IMU.write((uint8_t)Serial.read());
    while (IMU.available())    Serial.write((uint8_t)IMU.read());
}
```

## 로켓 환경 권장 (상황별 설정 가이드, 미적용 — 팀 결정 필요)

진동이 심한 환경 프로파일: `<cg>` + `<avca_e1>`(AVC 진동제거 ON) + `<raa_t0>`(RAA off)
+ 필요시 `<lpfa>` 조정. 발사장 도착 후 `<cmf>` 재캘리 권장.

## 주의

- **soa3(중력보정 Global)에서는 정지 시 가속도 3축 모두 ≈ 0**이다(2026-07-25 실측
  (0.037, -0.020, -0.002)g 확인). 발사 판정 `fabs(z_accel)>2`는 "순수 가속 2g"를
  의미하게 되고 장착 방향과 무관해짐. Kalman(accel_z_in)에는 중력이 제거된 글로벌
  수직가속도가 들어가므로 비행 전 벤치에서 kf_alt/kf_vel 거동 확인 권장.
- 거리(sod)는 관성 적분 기반 단시간 추적용 — 드리프트 누적됨. 텔레메트리 참고용.
- 2026-07-25 이전 SD/비행 로그의 `pos` 필드는 세션에 따라 의미가 다름
  (som1 시절 = 지자기 µT, sod2 이후 = 거리 m).
